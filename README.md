# 🐍 Alimente-a-Cobrinha

Um jogo da cobrinha clássico, moderno e viciante, desenvolvido puramente com **HTML5, CSS3 e JavaScript**.

![Status do Projeto](https://img.shields.io/badge/Status-Conclu%C3%ADdo-brightgreen)
![Licença](https://img.shields.io/badge/Licen%C3%A7a-MIT-blue)

## 🎮 Funcionalidades

- **3 Níveis de Dificuldade**:
  - 🟢 **Fácil**: Sem colisão com paredes e velocidade moderada.
  - 🟡 **Normal**: Colisão com paredes e velocidade padrão.
  - 🔴 **Difícil**: Colisão com paredes e velocidade progressiva.
- **Sistema de Medalhas**: Conquiste medalhas de Bronze, Prata, Ouro e Diamante conforme sua pontuação aumenta.
- **Efeitos de Áudio**: Sons retro-estilizados para comer, subir de nível e game over.
- **Músicas de Fundo**: Trilhas sonoras que mudam conforme o nível.
- **Recordes Locais**: Tabela de classificação persistente no seu navegador.
- **Totalmente Responsivo**: Jogue no computador (teclas de seta/WASD) ou no celular (controles touch e swipe).

## 🚀 Como Jogar

Você pode jogar o "Alimente-a-Cobrinha" de duas formas:

1. **Localmente**:
   - Clone este repositório.
   - Abra o arquivo `index.html` em qualquer navegador moderno.

2. **GitHub Pages** (Se ativado):
   - Acesse o link do seu GitHub Pages para jogar online.

### Controles
- **Setas / WASD**: Movimentam a cobrinha.
- **Espaço**: Pausa o jogo.
- **Touch/Swipe**: Arraste o dedo na tela para mudar a direção.

## 🛠️ Tecnologias Utilizadas

- **HTML5 Canvas** para a renderização do jogo.
- **CSS3** para o design moderno e efeitos de vidro (glassmorphism).
- **Vanilla JavaScript** para toda a lógica, sem dependências externas.
